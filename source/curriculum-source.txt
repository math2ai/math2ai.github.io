# Chapter 1. Numbers and linear algebra
Scalar|A scalar is one number. In this course, scalars are real numbers, which can lie anywhere on the number line.|x ∈ ℝ|A temperature reading is 24.5 °C. Its numerical value, 24.5, is a scalar.|One dial shows one number. Later, many dials will become a vector.|Which object is a scalar?|7.5 ~ (7.5, 2) ~ A table of 12 readings ~ A list of three temperatures|A scalar is a single number. A vector or matrix contains several scalar entries. The unit explains what a measured number means.|This means “x is a real number.”
Variable|A variable is a symbol whose value can vary within a specified set. An equation states a relationship between values.|y = 2x + 1|If x = 3, then y = 2 × 3 + 1 = 7.|A labeled empty box can hold different numbers while the rule stays the same.|For y = 2x + 1, what is y when x = 4?|9 ~ 8 ~ 6 ~ 5|Substitute 4 for x: 2 × 4 + 1 = 9. The symbol changes its value; the rule does not change.
Function|A function assigns exactly one output to each allowed input. Its domain is the set of allowed inputs.|f: ℝ → ℝ,   f(x) = x²|f(3) = 9 and f(−3) = 9. Different inputs may share an output.|A machine follows one recipe for each input, even if two ingredients produce the same result.|A function sends input 2 to 7 and input 5 to 7. If you observe output 7, can you identify which of these inputs was used?|No; either 2 or 5 could have produced it ~ Yes; the input must be 2 ~ Yes; the input must be 5 ~ This cannot be a function|Both listed inputs produce 7, so this output alone cannot distinguish them. Each input still has exactly one output.
Units|A physical quantity is a numerical value multiplied by a unit. Only quantities with compatible dimensions can be added.|distance = speed × time|3 metres/second × 4 seconds = 12 metres. Seconds cancel.|Units are labels on measuring cups. Mixing litres with metres makes no meaningful total.|At 5 metres/second for 6 seconds, how far do you travel?|30 metres ~ 30 seconds ~ 11 metres ~ 1.2 metres|Multiply speed by duration. Units are part of the calculation, not decoration. A model must preserve them when reading or answering questions about data.
Vector|A vector in ℝⁿ is an ordered list of n real numbers. Each position is a coordinate or feature. Add or subtract vectors of the same length by combining matching coordinates.|x = (x₁, …, xₙ);   2x = (2x₁, …, 2xₙ)|If x = (2, 3), then 2x = (4, 6). Order matters: (2, 3) ≠ (3, 2).|A vector is a dashboard: each dial has its own fixed position.|If x = (2, 5), what is 3x?|(6, 15) ~ (5, 8) ~ 21 ~ (15, 6)|Scalar multiplication multiplies every coordinate. It does not add 3, collapse the list, or reverse its order.
Matrix|A matrix is a rectangular array of numbers with m rows and n columns. Entry Aᵢⱼ lies in row i, column j. Matching shapes allow entrywise addition; multiplying a matrix by a scalar multiplies every entry. Diagonal entries Aᵢᵢ have matching row and column indices.|A ∈ ℝᵐˣⁿ;   A = [[1, 2, 3], [4, 5, 6]]|This 2 × 3 matrix has six entries. A₂₃ = 6. Each horizontal row has three entries.|A spreadsheet with numbered rows and columns is a matrix when its cells are numbers.|What is A₂₁ in A = [[1, 2], [3, 4]]?|3 ~ 2 ~ 1 ~ 4|The first subscript selects the row, the second selects the column. Row 2, column 1 contains 3.
Tensor|In machine learning, a tensor is an array of numbers organized along axes. A scalar has no axes, a vector one, and a matrix two. A stack of tables has three: table, row, and column. Its shape lists the length of each axis in that order.|shape = (tables, rows, columns)\nentries = tables × rows × columns|A stack of 2 tables, each with 3 rows and 4 columns, has shape (2, 3, 4): 3 axes and 2×3×4 = 24 entries. For a smaller stack with tables [[1,2],[3,4]] and [[5,6],[7,8]], T₂₁₂ = 6. Its shape is (2, 2, 2).|A book of number tables needs a page, row, and column to locate one number.|A tensor has tables [[2,8],[5,1]] and [[9,4],[6,3]]. Indices start at 1 and mean (table, row, column). What is T₁₂₁?|5 ~ 8 ~ 9 ~ 6|The first index selects the first table. Its second row is [5,1], whose first entry is 5.|Tᵢⱼₖ selects table i, row j, column k. Indices start at 1.
Summation|Summation adds a specified sequence of terms. The symbol Σ says which index varies and where it starts and ends.|Σᵢ₌₁ⁿ xᵢ = x₁ + x₂ + ⋯ + xₙ|For x = (2, 4, 6), Σᵢ₌₁³ xᵢ = 12. Their mean is 12/3 = 4.|Σ is an instruction to sweep the named numbers into one adding bucket.|What is Σᵢ₌₁³ i²?|14 ~ 6 ~ 9 ~ 36|Add 1² + 2² + 3² = 1 + 4 + 9 = 14. The index tells us which terms to use.
Dot product|The dot product of two equal-length vectors multiplies matching coordinates and adds the products.|x · w = Σᵢ xᵢwᵢ|With x = (2, 3) and w = (4, 5), x · w = 8 + 15 = 23.|A shopping bill multiplies each quantity by its price, then adds the costs.|What is (1, 4) · (3, 2)?|11 ~ 10 ~ (3, 8) ~ 24|The products are 3 and 8; their sum is 11. Keeping (3, 8) would be elementwise multiplication, not a dot product.
Matrix multiplication|For A of shape m × n and B of shape n × p, AB has shape m × p. Each entry is a row-column dot product.|(AB)ᵢⱼ = Σₖ₌₁ⁿ AᵢₖBₖⱼ|[[1, 2], [3, 4]] × [[5], [6]] = [[17], [39]]. First entry: 1×5 + 2×6 = 17. Second: 3×5 + 4×6 = 39.|Each row submits a shopping list to each column of prices.|A is 2 × 3 and B is 3 × 4. What shape is AB?|2 × 4 ~ 3 × 3 ~ 4 × 2 ~ 6 × 12|The inner dimensions, 3 and 3, must match. The outer dimensions form the result, 2 × 4. Matrix multiplication is generally order-dependent.
Transpose|The transpose of a matrix exchanges rows and columns. It changes an m × n matrix into an n × m matrix.|(Aᵀ)ᵢⱼ = Aⱼᵢ|If A = [[1, 2, 3]], then Aᵀ = [[1], [2], [3]].|Turn a row of books into a vertical stack without changing their order.|What is the transpose of a 2 × 5 matrix?|A 5 × 2 matrix ~ A 2 × 5 matrix with doubled entries ~ A 10 × 1 matrix ~ A 2 × 5 matrix with all entries negated|Transposing swaps the two axes. It does not change the values, flatten the matrix, or undo a transformation.
Linear transformation|A linear transformation preserves vector addition and scalar multiplication. In finite dimensions, it can be represented by a matrix. Adding a fixed shift to a linear map gives an affine map. A nonzero shift breaks linearity because zero no longer maps to zero.|T(ax + by) = aT(x) + bT(y)|For A = [[2, 0], [0, 3]], A(1, 2) = (2, 6). The first coordinate doubles; the second triples.|Stretch a sheet by fixed factors along its axes, keeping the origin pinned.|Which function is linear in the mathematical sense?|f(x) = 3x ~ f(x) = x + 3 ~ f(x) = x² ~ f(x) = max(0, x)|A linear map sends zero to zero and obeys superposition. The familiar straight-line function 3x + b is affine when b is nonzero.
Euclidean distance|The Euclidean norm measures vector length. The distance between two vectors is the norm of their difference.|‖x‖₂ = √(Σᵢ xᵢ²);   d(x, y) = ‖x − y‖₂|Between (0, 0) and (3, 4), distance = √(9 + 16) = 5.|Stretch a straight string between two pins instead of following the grid streets.|What is the Euclidean distance from (2, −1) to (7, 11)?|13 ~ 17 ~ 169 ~ 7|The coordinate differences are 5 and 12. Their squared sum is 25 + 144 = 169, whose square root is 13.
Eigenvalues and eigenvectors|An eigenvector is a nonzero vector whose direction stays on the same line after a square matrix acts on it. Its eigenvalue gives the scaling, including a possible reversal.|Av = λv,   v ≠ 0|For A = [[2,0],[0,3]], A(1,0) = (2,0). Thus (1,0) is an eigenvector with eigenvalue 2. The other coordinate direction has eigenvalue 3.|Some arrows survive a stretch pointing along their original line, although their length or orientation can change.|For A = [[−4,0],[0,7]] and v = (2,0), what is the eigenvalue associated with v?|−4 ~ 4 ~ −8 ~ 7|Multiplication gives Av = (−8,0) = −4(2,0). The eigenvalue is −4, the scale factor multiplying the whole vector.|The nonzero vector v is an eigenvector; λ is its eigenvalue.
Singular value decomposition|Singular value decomposition (SVD) separates a real matrix into input directions, nonnegative scale factors, and output directions. The scale factors are its singular values. It works for rectangular matrices too.|A = UΣVᵀ|For A = [[3,0],[0,1]], the singular values are 3 and 1. Keeping only the first gives A₁ = [[3,0],[0,0]], a rank-one approximation.|Rotate the viewpoint, stretch along perpendicular axes, then rotate again. Keeping the strongest stretches compresses the transformation.|For A = [[1,0],[0,4]], keep only the direction with the largest singular value. Which matrix results?|[[0,0],[0,4]] ~ [[1,0],[0,0]] ~ [[1,0],[0,4]] ~ [[0,4],[0,0]]|Keeping the scale 4 and setting the scale 1 to zero gives [[0,0],[0,4]]. This approximates A using one direction.|The columns of V give perpendicular (orthogonal) input directions; U gives the corresponding output directions. Σ is the diagonal matrix of singular values.\n\nRank counts the nonzero singular values. A low-rank approximation uses fewer independent directions to approximate A. Keep the largest k singular values and set the rest to zero: the result has rank at most k, and some information can be lost.
# Chapter 2. Probability and calculus
Probability|Probability measures how likely an event is on a scale from 0 to 1. Probabilities of all possible, nonoverlapping outcomes add to 1. Independent trials do not change one another’s outcome probabilities; multiply their probabilities to find the chance of a specified combination.|0 ≤ P(A) ≤ 1;   Σᵢ P(Aᵢ) = 1|For a fair six-sided die, P(even) = 3/6 = 0.5.|Divide one whole pie among the possible outcomes. Larger slices mean greater probability.|A fair die is rolled. What is P(rolling more than 4)?|1/3 ~ 1/2 ~ 2/3 ~ 1/6|The favorable outcomes are 5 and 6: two of six equally likely outcomes. A probability describes uncertainty, not certainty about one trial.
Conditional probability|Conditional probability measures how likely A is when B is known to have occurred, provided P(B) > 0. Independent events satisfy P(A given B) = P(A): knowing B does not change the probability of A. Conditioning describes observed probabilities; it does not by itself establish a cause.|P(A ∣ B) = P(A ∩ B) / P(B)|Of four red balls, one is striped. P(striped ∣ red) = 1/4.|Once you enter the red-ball room, count only the balls inside that room.|Of 10 samples, 4 are deep and 3 of those are hot. P(hot given deep)?|3/4 ~ 3/10 ~ 4/10 ~ 4/3|Conditioning changes the relevant denominator to the four deep samples. P(A given B) generally differs from P(B given A).
Bayes’ theorem|Bayes’ theorem updates the probability of a hypothesis after observing evidence. The prior is its probability before the evidence; the posterior is its probability after the update. The likelihood is the probability of that evidence if the hypothesis holds.|P(H ∣ E) = P(E ∣ H)P(H) / P(E),   P(E) > 0|Of 100 parts, 10 are defective. A test flags 8 defective parts and 9 good parts. Among 17 flagged parts, 8 are defective: P(defective ∣ flagged) = 8/17.|Revise the odds on a suspect when a clue arrives, remembering how common each suspect was to begin with.|An email filter flags 12 spam messages and 18 legitimate messages. What fraction of the flagged messages are spam?|2/5 ~ 3/5 ~ 2/3 ~ 1/12|There are 12 + 18 = 30 flagged messages. The fraction that are spam is 12/30 = 2/5.|H is the hypothesis; E is the observed evidence.
Expected value|The expected value of a discrete numerical outcome is its probability-weighted average.|E[X] = Σₓ x P(X = x)|A reward is 0 or 10 with equal probability. E[X] = 0.5 × 0 + 0.5 × 10 = 5.|The balancing point of possible rewards can sit where no individual reward exists.|A game pays 8 with probability 1/4 and 0 otherwise. Expected payout?|2 ~ 8 ~ 4 ~ 0.25|The weighted average is 8 × 1/4 + 0 × 3/4 = 2. You need not receive exactly 2 in any play.
Variance|Variance is the expected squared distance from the mean μ. Standard deviation σ is its square root.|μ = E[X];   Var(X) = E[(X − μ)²];   σ = √Var(X)|Values 2 and 6 are equally likely. Mean = 4. Variance = [(2−4)² + (6−4)²]/2 = 4. Standard deviation = √4 = 2.|The mean locates the center of the arrow hits; variance describes how widely they spread.|For equally likely values 1 and 7, what is the population variance?|9 ~ 3 ~ 18 ~ 4|The mean is 4. Both squared deviations are 9, and their probability-weighted average is 9.
Covariance and correlation|Covariance measures joint variation around two means. Correlation divides covariance by both standard deviations, giving a unitless measure of linear association when both deviations are positive. Correlation lies between −1 and 1. Zero correlation rules out linear association, not every dependence. Association alone does not establish a cause.|Cov(X,Y) = E[(X−μX)(Y−μY)];  ρ = Cov(X,Y)/(σXσY)|The equally likely pairs (1,2) and (3,6) have means 2 and 4. Covariance = [(-1)(-2)+(1)(2)]/2 = 2. Standard deviations are 1 and 2, so correlation = 1.|Two dancers may move together, oppositely, or without a consistent linear rhythm.|For equally likely pairs (0,6) and (4,2), what is the covariance?|−4 ~ 4 ~ −8 ~ 0|The means are 2 and 4. The deviation products are (−2)×2 and 2×(−2), so covariance is (−4−4)/2 = −4.
Monte Carlo estimation|Monte Carlo estimation uses random samples to approximate an expected value. Average the results of independent draws from the target distribution. More samples usually make the estimate more stable, but cannot correct a wrong simulation model.|E[f(X)] ≈ (1/n)Σᵢ f(Xᵢ)|Four simulated rewards are 0, 2, 4, and 6. Their sample average is 12/4 = 3, an estimate of expected reward rather than its exact value.|Taste many randomly chosen spoonfuls to estimate the average flavor of a large pot.|Six simulated rewards are 2, 3, 7, 8, 9, and 13. What is their Monte Carlo estimate of expected reward?|7 ~ 42 ~ 6 ~ 8|Their sum is 42. Dividing by the six draws gives the sample-average estimate 7, not a guarantee of the true expectation.|Average f over n samples from the target distribution. A random seed lets the same implementation reproduce the sampled draws.
Exponential and logarithm|An exponential raises a fixed base to a variable power. A logarithm gives the power needed to obtain a number. Natural logarithms use the base e ≈ 2.718.|log_b(bˣ) = x;   ln(x) = log_e(x)\nln(ab) = ln(a) + ln(b)|2³ = 8, so log₂(8) = 3. Likewise, e² ≈ 7.389, so ln(7.389) ≈ 2.|An exponential climbs a multiplicative ladder; a logarithm tells you how many rungs you climbed.|What is ln(e³)?|3 ~ e ~ 9 ~ 1|The logarithm reverses exponentiation. In later probability losses, logarithms also turn products of probabilities into sums.|The base b must be positive and different from 1. A real logarithm requires a positive input; the product rule assumes a,b > 0.
Derivative|The derivative is a function's instantaneous rate of change, defined by the limit of slopes over shrinking intervals. A local minimum is lowest among nearby inputs; a global minimum is lowest over the whole domain. A zero derivative alone guarantees neither.|f′(x) = limₕ→₀ [f(x + h) − f(x)] / h\nd(xⁿ)/dx = n xⁿ⁻¹|For f(x) = x²: f(3.01) − f(3) = 0.0601. The slope over this interval is 0.0601/0.01 = 6.01, close to f′(3) = 6.|A speedometer measures the slope of your distance-versus-time journey at this instant.|For f(x) = x², what is the derivative at x = 4?|8 ~ 16 ~ 4 ~ 2|The derivative is 2x, so its value is 8. The function's value is 16. Local slope and height are different quantities.|The second equation is the power rule, shown here for a positive integer n.
Integral|A definite integral is the limit of sums of a function's values times small interval widths. It measures signed accumulation.|∫ₐᵇ f(t) dt = limₙ→∞ Σᵢ₌₁ⁿ f(a + iΔt)Δt\nΔt = (b − a)/n|A flow of 2 litres/second for 3 seconds delivers ∫₀³ 2 dt = 6 litres.|A derivative reads the tap's flow rate; an integral counts the water collected in the bucket.|A constant speed of 4 metres/second lasts 5 seconds. Integral of speed?|20 metres ~ 9 metres ~ 0.8 metres ~ 20 metres/second|For the constant speed, 4 × 5 = 20 metres. Integrating nonnegative speed gives distance; integrating signed velocity gives displacement. The displayed equal-width limit defines the integral for continuous functions, and more generally for Riemann-integrable functions.
Gradient|For a scalar function of several variables, the gradient collects its partial derivatives. Each partial varies one coordinate while holding the others fixed. When nonzero, the gradient points in the direction of fastest local increase among directions of equal Euclidean length.|∇L = (∂L/∂x, ∂L/∂y)|If L = x² + 3y², then ∇L = (2x, 6y). At (1, 2), it is (2, 12).|A hill's gradient is a local uphill compass, with one component for each direction.|For L = x² + y² at (2, 3), what is ∇L?|(4, 6) ~ 13 ~ (2, 3) ~ (−4, −6)|Differentiate with respect to each coordinate. The negative gradient points locally downhill; the gradient itself points toward fastest local increase under Euclidean geometry.
Hessian and curvature|The Hessian is the matrix of second partial derivatives of a scalar function. It describes local curvature.\n\nFor smooth functions, its eigenvalues help classify a stationary point where the gradient is zero. All-positive eigenvalues (positive definite) imply a strict local minimum; mixed positive and negative eigenvalues imply a saddle, rising in some directions and falling in others. Zero Hessian eigenvalues can leave the classification inconclusive.|Hᵢⱼ = ∂²f / (∂xᵢ∂xⱼ)|For f(x,y)=x²+3y², H=[[2,0],[0,6]]. At (0,0), the gradient is zero and both curvature directions are positive, so this is a strict local minimum.|A slope tells you which way a road tilts; curvature tells you how that slope changes.|For f(x,y) = 4x² + 2y², what is the Hessian in (x,y) order?|[[8,0],[0,4]] ~ [[4,0],[0,2]] ~ [[8,4],[4,4]] ~ [[4,0],[0,8]]|The first partials are 8x and 4y. Differentiating again gives diagonal entries 8 and 4, with zero mixed partials.
Chain rule|When one function feeds another, a change passes through both. The chain rule multiplies their local derivatives to find the derivative of the combined function.|dy/dx = f′(g(x)) g′(x)|Let u = 2x and y = u². At x = 3, u = 6. The two slopes are du/dx = 2 and dy/du = 12, so dy/dx = 12×2 = 24. If y is a sum of two paths from x, compute each path’s derivative and add them: for y = (2x)² + (3x)², dy/dx = 8x + 18x.|Linked gears multiply their speed ratios. A change travels through every gear.|For y = (3x)², what is dy/dx at x = 2?|36 ~ 12 ~ 18 ~ 6|Let u = 3x. Then dy/dx = 2u × 3 = 18x = 36. Forgetting the inner derivative loses a factor of 3.|Here y = f(g(x)): the output of g becomes the input of f.
Optimization|An objective assigns a score to each choice. Optimization finds an allowed choice with the smallest or largest score. The allowed choices form the constraint set C.|x* = arg minₓ∈C L(x)|For L(x) = (x − 3)² and C = [0, 2], x* = 2 and L(x*) = 1.|Find the lowest campsite inside the fence. A lower valley outside it is unavailable.|Minimize (x − 5)² subject to 0 ≤ x ≤ 3. Which x wins?|3 ~ 5 ~ 0 ~ 2|The unconstrained minimum is 5, but it is not allowed. Among allowed inputs, 3 is closest to 5. The optimum input differs from its objective value.
Lagrange multipliers|Lagrange multipliers help find candidates for optimization with equality constraints. For one smooth constraint with a nonzero gradient, a candidate’s objective gradient balances a multiple of the constraint gradient. The candidate must also satisfy the constraint. These conditions do not guarantee a minimum.|ℒ(x,λ) = f(x) + λg(x)\n∇f(x) + λ∇g(x) = 0;   g(x) = 0|Minimize x²+y² subject to x+y=2. Conditions 2x+λ=0 and 2y+λ=0 imply x=y. The constraint then gives x=y=1 and objective 2.|Find the lowest contour that touches the permitted path without leaving it.|To minimize x² + 3y² subject to x + y = 8, the stationary conditions give x = 3y. Which point satisfies both conditions?|(6,2) ~ (4,4) ~ (2,6) ~ (8,0)|Substitute x = 3y into x+y = 8 to obtain 4y = 8. Thus y = 2 and x = 6.|Here f is the objective and g(x) = 0 is the equality constraint. Inequality constraints need additional conditions.
Gradient descent|Gradient descent updates a variable or parameter vector in the direction opposite its gradient. The learning rate η sets the step size. A sufficiently small step can lower the loss.|θ⁺ = θ − η∇L(θ),   η > 0|For L(θ) = θ², θ = 3 and η = 0.1: θ⁺ = 3 − 0.1×6 = 2.4. The loss falls from 9 to 2.4² = 5.76.|Feel the ground's slope, take a short downhill step, then measure again.|For θ = 4, gradient 6, and learning rate 0.1, what is the next θ?|3.4 ~ 4.6 ~ 0.6 ~ −2|Subtract 0.1 × 6 from 4. Large steps can increase the loss, and nonconvex objectives need not lead to a global minimum.
# Chapter 3. Learning from data
Dataset and features|A dataset collects examples. Features describe each example numerically. In supervised learning, each input x is paired with a target answer y.|D = {(xᵢ, yᵢ)}ᵢ₌₁ᴺ|Two rooms have features (length, width): (2, 3) and (4, 3) metres. X = [[2, 3], [4, 3]] has two rows and two features per row.|Features are the clues on a detective's case card; the target is the answer being learned.|There are 20 samples and 4 features per sample. Shape of X?|20 × 4 ~ 4 × 4 ~ 20 × 20 ~ 80 × 1 only|By the row-per-sample convention, X has 20 rows and 4 columns. A measured target must not accidentally be included as an input feature.
Linear regression|Linear regression predicts a numerical target using a weighted sum of features plus an intercept. A residual is target minus prediction. Patterns in residuals can show relationships the fitted line has missed.|ŷ = w · x + b|A toy taxi fare model is ŷ = 2x + 3 dollars for x kilometres. At 5 km: ŷ = 2×5 + 3 = $13. The intercept is the starting fare.|A recipe assigns each ingredient a fixed contribution, then adds a fixed starting amount.|A regression model predicts ŷ = 4x + 2. What does it predict at x = 3?|14 ~ 12 ~ 18 ~ 10|Substituting x = 3 gives 4×3 + 2 = 14. The intercept is added after the weighted input.
Mean squared error|Mean squared error is the average squared difference between predictions and targets. It penalizes larger errors more strongly.|MSE = (1/N) Σᵢ (ŷᵢ − yᵢ)²|Predictions (2, 5), targets (3, 3): MSE = (1 + 4)/2 = 2.5.|Large misses get disproportionately heavier penalty weights than small misses.|Errors are 1 and 3. What is their MSE?|5 ~ 2 ~ 4 ~ 10|Square first: 1 and 9. Then average: 5. The loss has squared target units, so it is not directly an average absolute error.
Supervised learning|Supervised learning uses examples with known answers to learn a rule for new inputs. A loss measures prediction error; training adjusts the rule to reduce that loss. Using the learned rule to make predictions is called inference. Classification predicts a category; regression predicts a number. Generalization means performing well on new examples.|minimize (1/N) Σᵢ ℓ(f_θ(xᵢ), yᵢ)|Inputs 1, 2, 3 paired with targets 2, 4, 6 suggest f(x) = 2x; it predicts 8 for input 4.|A coach gives both a problem and a worked answer so a learner can improve its rule.|Which task is supervised learning?|Learn rock type from logs paired with rock labels ~ Compress logs without rock labels ~ Choose actions using only rewards ~ Store a file unchanged|Supervision supplies target answers for inputs. Those targets may be numeric or categorical. The learned rule still needs evaluation on unseen examples.|The model f uses parameters θ. The loss ℓ scores one prediction against its target; training minimizes the average loss.
Parameter and hyperparameter|A parameter is fitted during learning. A hyperparameter configures the model or training procedure rather than being fitted by that procedure.|ŷ = wx + b;   w⁺ = w − η ∂L/∂w|In this update, w = 2 is a parameter; the chosen learning rate η = 0.01 is a hyperparameter.|The learner adjusts recipe quantities; the teacher chooses how large each adjustment may be.|A training procedure fits weights and biases but stops after a user-chosen limit of 500 updates. Which quantity is a hyperparameter?|The chosen limit of 500 updates ~ A weight fitted by the procedure ~ A bias fitted by the procedure ~ A fitted regression coefficient|The update limit configures the training procedure and is chosen outside its parameter-fitting steps. The fitted coefficients are parameters.
Training, validation and test|Training data fit parameters; validation data guide model choices; a held-out test estimates performance after those choices are fixed.|D = Dₜᵣₐᵢₙ ∪ Dᵥₐₗ ∪ Dₜₑₛₜ|A 100-well study might use 70 wells to train, 15 to choose settings, and 15 for final testing.|Practice exercises, a mock exam, and a sealed final exam have different jobs.|Which set should choose the learning rate?|Validation set ~ Final test set repeatedly ~ All data including the final test ~ The alphabetic first well only|Use validation performance to choose settings. Reusing the final test to tune the model makes it part of the development process.|These sets are disjoint: an example belongs to only one split.
Data leakage|Data leakage occurs when model development uses information that would be unavailable in the intended prediction setting. A window is a short consecutive segment of a sequence, so nearby windows can include the same measurements.|train wells ∩ test wells = ∅|Training uses a well segment at depths 100, 101, 102 m. Testing uses 101, 102, 103 m from the same well. Two of three measurements are shared.|An exam is misleading when the practice sheet contains copies of its questions.|To measure generalization to unseen wells, how should you split data?|Keep each well entirely in one split ~ Randomly split overlapping windows ~ Normalize using all test values first ~ Put duplicate rows in every split|Nearby measurements and overlapping windows are strongly related. Split at the deployment-relevant group before creating windows and fitting preprocessing.|For testing on new wells, keep every well entirely within one split.
Normalization|Normalization rescales data to a chosen reference scale. Standardization, one common method, subtracts the mean μ and divides by the standard deviation σ.|z = (x − μ)/σ,   σ > 0|Training data give μ = 100 and σ = 20. A new value x = 140 becomes z = 2.|Convert different measuring rulers into a common “distance from typical” scale.|With training mean 15 and standard deviation 4, what standardized value does x = 27 become?|3 ~ 12 ~ 6.75 ~ −3|Standardization gives (27−15)/4 = 12/4 = 3.|This is standardization: subtract the mean, then divide by the standard deviation.
k-nearest neighbors|k-nearest neighbors predicts from the k closest stored training examples under a chosen distance. Classification commonly uses a vote; regression commonly averages their targets.|ŷ(x) = (1/k)Σᵢ∈Nₖ(x) yᵢ|The three nearest examples have targets 2, 4, and 9. An unweighted k=3 regressor predicts (2+4+9)/3 = 5.|Ask the nearby houses what usually happens on this street.|A k=3 regressor's nearest target values are −2, 5, and 9. What is its unweighted prediction?|4 ~ 12 ~ 5 ~ 6|An unweighted regressor averages the three targets: (−2+5+9)/3 = 4.|For regression, average the targets of the k nearest training examples, denoted Nₖ(x).
Decision trees|A decision tree routes an input through feature tests to a leaf. A classification leaf predicts a class; a regression leaf often predicts the average training target in that leaf. The first test is the root. Testing one feature at a time is called an axis-aligned split.|feature ≤ threshold → left branch\nfeature > threshold → right branch|A tree predicts 2 when x≤5 and 8 otherwise. Input x=4 follows the left branch and receives prediction 2.|A sequence of signposts sends each traveler down one route to a destination.|A tree predicts 2 if x≤5, otherwise 8. What does it predict for x=6?|8 ~ 2 ~ 5 ~ 6|Since 6>5, use the right branch. Overfitting|Overfitting occurs when a model learns training-specific details that do not generalize to the intended new data. Underfitting is failing to learn useful patterns even in training data. Variograms and kriging|A semivariogram shows how differences between observations change with their separation. For sample pairs at a similar distance, average half the squared differences; this is their estimated semivariance.\n\nKriging uses this spatial pattern to weight observations when estimating an unsampled location. Ordinary kriging assumes an unknown constant mean within the modeled neighborhood; its weights sum to 1.|γ̂(h) = Σpairs [z(sᵢ)−z(sⱼ)]² / (2N(h))\nẑ(s₀) = Σᵢ wᵢz(sᵢ),   Σᵢwᵢ = 1|At one distance bin, two pairs have value differences 2 and 4. Estimated semivariance is (2²+4²)/(2×2) = 5. Kriging weights would then require a fitted model and sample geometry.|Nearby clues can inform a missing location, but their usefulness depends on both distance and the pattern of similarity.|Three pairs in a distance bin have value differences −1, 3, and 4. What is their estimated semivariance?|13/3 ~ 26/3 ~ 26 ~ 13/6|Square all three differences and divide by twice the pair count: (1+9+16)/(2×3) = 26/6 = 13/3.|For separation h, average squared differences over N(h) sample pairs and divide by 2.
