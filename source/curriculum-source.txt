# Chapter 1. Numbers and linear algebra
Scalar|A scalar is one number. In this course, scalars are real numbers, which can lie anywhere on the number line.\n\nThe important distinction is one value versus a collection of values. A scalar can record a temperature, a count, or a prediction error. Its numerical type does not tell us what it measures: the meaning and units come from the problem.|x ∈ ℝ|A temperature reading is 24.5 °C. Its numerical value, 24.5, is a scalar.\n\nA second reading might be 25.0 °C. Subtracting the first numerical value from the second gives a rise of 0.5 °C: two scalar inputs produce one scalar difference. Keeping both readings is a collection, rather than a single scalar. Later, a learning algorithm will also use a scalar to summarize how badly its predictions missed their targets.|One dial shows one number. Later, many dials will become a vector.|Which object is a scalar?|7.5 ~ (7.5, 2) ~ A table of 12 readings ~ A list of three temperatures|A scalar is a single number. A vector or matrix contains several scalar entries. The unit explains what a measured number means.|This means “x is a real number.”
Variable|A variable is a symbol whose value can vary within a specified set. An equation states a relationship between values.\n\nSymbols let us state one relationship and reuse it for many cases. Keep track of the role of each symbol: some values are supplied, some are calculated, and some are quantities we want to find. Changing a symbol's value does not change the rule that uses it.|y = 2x + 1|If x = 3, then y = 2 × 3 + 1 = 7.\n\nRead the calculation as a small process: take the input 3, double it to get 6, then add the fixed 1. The resulting 7 belongs to y. If the input changes, substitute the new value everywhere x occurs. This is how a single formula can describe many measurements or predictions without rewriting the calculation each time.|A labeled empty box can hold different numbers while the rule stays the same.|For y = 2x + 1, what is y when x = 4?|9 ~ 8 ~ 6 ~ 5|Substitute 4 for x: 2 × 4 + 1 = 9. The symbol changes its value; the rule does not change.|Here x is the input value and y is the resulting value. The rule doubles the input, then adds 1.
Function|A function assigns exactly one output to each allowed input. Its domain is the set of allowed inputs.\n\nA function separates a reusable rule from the particular input passed to it. This is the basic shape of a prediction system: receive an allowed input, apply a rule, return an output. Knowing the output need not reveal the original input, because a function can discard information.|f: ℝ → ℝ,   f(x) = x²|f(3) = 9 and f(−3) = 9. Different inputs may share an output.\n\nThe rule squares its input. Starting with 3 or with −3 therefore reaches the same 9. The rule is perfectly definite in the forward direction, yet “which input produced 9?” has two answers here. This distinction matters whenever we transform measurements: an easy forward calculation may be impossible to undo uniquely.|A machine follows one recipe for each input, even if two ingredients produce the same result.|A function sends input 2 to 7 and input 5 to 7. If you observe output 7, can you identify which of these inputs was used?|No; either 2 or 5 could have produced it ~ Yes; the input must be 2 ~ Yes; the input must be 5 ~ This cannot be a function|Both listed inputs produce 7, so this output alone cannot distinguish them. Each input still has exactly one output.|f names the function, x is its input, and f(x) is its output. The notation ℝ → ℝ says both inputs and outputs are real numbers.
Units|A physical quantity is a numerical value multiplied by a unit. Only quantities with compatible dimensions can be added.\n\nUnits help check whether an operation means what we think it means. Convert compatible measurements to a common unit before adding or comparing them. A computer can calculate with mismatched units without noticing; the result can still be meaningless.|distance = speed × time|3 metres/second × 4 seconds = 12 metres. Seconds cancel.\n\nThink of four one-second intervals. Each contributes 3 metres, so four such intervals contribute 12 metres in total. The same speed is 300 centimetres per second; multiplying by 4 gives 1,200 centimetres, the same distance. A changed numerical representation should not change the physical prediction.|Units are labels on measuring cups. Mixing litres with metres makes no meaningful total.|At 5 metres/second for 6 seconds, how far do you travel?|30 metres ~ 30 seconds ~ 11 metres ~ 1.2 metres|Multiply speed by duration. Units are part of the calculation, not decoration. A model must preserve them when reading or answering questions about data.
Vector|A vector in ℝⁿ is an ordered list of n real numbers. Each position is a coordinate or feature. Add or subtract vectors of the same length by combining matching coordinates.\n\nThe order gives the numbers their roles. A vector might hold horizontal and vertical displacement, or two measurements of one object. Operations on vectors only make sense when the corresponding positions refer to compatible quantities. This is how a model can process several inputs together while keeping their identities.|x = (x₁, …, xₙ);   2x = (2x₁, …, 2xₙ)|If x = (2, 3), then 2x = (4, 6). Order matters: (2, 3) ≠ (3, 2).\n\nFor a displacement, start at the origin, move 2 units horizontally and 3 vertically. Doubling the vector doubles both movements, producing the same direction with twice the length. If instead the entries mean temperature and pressure, scaling still works coordinate by coordinate, but the geometric interpretation requires care because the units differ.|A vector is a dashboard: each dial has its own fixed position.|If x = (2, 5), what is 3x?|(6, 15) ~ (5, 8) ~ 21 ~ (15, 6)|Scalar multiplication multiplies every coordinate. It does not add 3, collapse the list, or reverse its order.|x names the whole vector; xᵢ is its entry at position i. There are n entries, numbered 1 through n. ℝⁿ denotes vectors with that many real coordinates.
Matrix|A matrix is a rectangular array of numbers with m rows and n columns. Entry Aᵢⱼ lies in row i, column j. Matching shapes allow entrywise addition; multiplying a matrix by a scalar multiplies every entry. Diagonal entries Aᵢᵢ have matching row and column indices.\n\nA matrix can organize many vectors: for example, one observation per row and one measured feature per column. Those meanings are part of the data specification. A matrix can also hold the coefficients of a transformation, which we will apply using matrix multiplication.|A ∈ ℝᵐˣⁿ;   A = [[1, 2, 3], [4, 5, 6]]|This 2 × 3 matrix has six entries. A₂₃ = 6. Each horizontal row has three entries.\n\nSuppose the first row describes observation A and the second describes observation B. Then the first feature is the column containing 1 and 4; the third feature is the column containing 3 and 6. Reading entry 6 means selecting observation B's third feature. Swapping rows changes observation order; swapping columns changes which measurement occupies each position.|A spreadsheet with numbered rows and columns is a matrix when its cells are numbers.|What is A₂₁ in A = [[1, 2], [3, 4]]?|3 ~ 2 ~ 1 ~ 4|The first subscript selects the row, the second selects the column. Row 2, column 1 contains 3.|A names the matrix. ℝᵐˣⁿ denotes real matrices with m rows and n columns. The subscripts i and j select a row and column, counted from 1.
Tensor|In machine learning, a tensor is an array of numbers organized along axes. A scalar has no axes, a vector one, and a matrix two. A stack of tables has three: table, row, and column. Its shape lists the length of each axis in that order.\n\nAn entry is one number stored at one position. The entry count is the total number of these positions, including zeros and repeated values. Multiply all the axis lengths to find it. This differs from the number of axes, which is how many lengths the shape lists.\n\nExtra axes preserve structure that a single long list would hide. For example, several observations can each contain a table of measurements. The tensor stores all of them together, but an axis has no built-in meaning: its name and ordering must be specified before indexing or combining the data.|shape = (tables, rows, columns)\nentries = tables × rows × columns|A stack of 2 tables, each with 3 rows and 4 columns, has shape (2, 3, 4): 3 axes and 2×3×4 = 24 entries. For a smaller stack with tables [[1,2],[3,4]] and [[5,6],[7,8]], T₂₁₂ = 6. Its shape is (2, 2, 2).\n\nTo find the displayed 6, first choose table 2, then its first row, then that row's second entry. Changing only the first index selects another table while keeping the same row and column. Flattening the stack into a list would keep its numbers, but recovering the table structure would also require remembering the original shape and ordering.|A book of number tables needs a page, row, and column to locate one number.|A tensor has tables [[2,8],[5,1]] and [[9,4],[6,3]]. Tᵢⱼₖ selects table i, row j, column k. Indices start at 1.
Summation|Summation adds a specified sequence of terms. The symbol Σ says which index varies and where it starts and ends.\n\nThe index is a bookkeeping device: expand the terms it names, then add each exactly once. Dividing a sum by the number of terms produces their arithmetic mean. Learning algorithms repeatedly use this pattern to combine contributions from many observations.|Σᵢ₌₁ⁿ xᵢ = x₁ + x₂ + ⋯ + xₙ|For x = (2, 4, 6), Σᵢ₌₁³ xᵢ = 12. Their mean is 12/3 = 4.\n\nThe three contributions are 2, 4, and 6; none is a multiplier or an extra index value. Their total is 12. Sharing that total equally across three positions gives the mean 4. A sum answers “how much altogether?” while a mean answers “how much per observation?” Doubling a dataset changes the sum but not its mean when all observations are duplicated.|Σ is an instruction to sweep the named numbers into one adding bucket.|What is Σᵢ₌₁³ i²?|14 ~ 6 ~ 9 ~ 36|Add 1² + 2² + 3² = 1 + 4 + 9 = 14. The index tells us which terms to use.|xᵢ is the term at position i; n is the number of terms. Start with i = 1 and add one term for each position through n. Here x names the full list.
Linear combinations|A linear combination scales vectors and adds the results. The scalar multipliers are called coefficients. Every vector must have the same number of coordinates, with matching meanings and compatible units.\n\nThink of the vectors as available movements and the coefficients as the amounts of each movement. Positive coefficients move along a vector, negative ones reverse it, and zero leaves it out. The coefficients need not add to one. This will let us describe which outputs a matrix or a model can build from its inputs.|y = au + bv|Take u = (1, 0) and v = (1, 2). Using coefficients 2 and 3 gives 2u = (2, 0) and 3v = (3, 6). Adding gives y = (5, 6).\n\nThe plot walks along the first scaled vector and then along the second, ending at the sum. Change the second coefficient to minus one: the second movement reverses and the result becomes (1, −2). The rule is unchanged; the coefficients choose the mixture.|Mixing two adjustable movements is like giving directions: take some steps east, then some steps along a second street.|For u = (2, 1) and v = (0, 3), what is 3u − v?|(6, 0) ~ (6, 6) ~ (2, −2) ~ (3, 0)|Tripling u gives (6, 3). Subtracting v changes only the second coordinate, leaving (6, 0).|Here u and v are the available vectors, a and b are real-number coefficients, and y is the resulting vector. Scale every coordinate before adding matching coordinates.
Dot product|The dot product of two equal-length vectors multiplies matching coordinates and adds the products.\n\nA dot product is a weighted total: each weight determines how much the matching input contributes. Positive weights add in the same direction, negative weights subtract, and zero weights ignore an input. This operation will be the core calculation inside a simple artificial neuron.|x · w = Σᵢ xᵢwᵢ|With x = (2, 3) and w = (4, 5), x · w = 8 + 15 = 23.\n\nImagine two products with quantities 2 and 3 and unit prices 4 and 5. Their costs are 8 and 15, totaling 23. Pairing a quantity with the wrong price would change the meaning. The same arithmetic can combine measured features into a score; learning will later mean adjusting those weights from examples.|A shopping bill multiplies each quantity by its price, then adds the costs.|What is (1, 4) · (3, 2)?|11 ~ 10 ~ (3, 8) ~ 24|The products are 3 and 8; their sum is 11. Keeping (3, 8) would be elementwise multiplication, not a dot product.|x and w are the two vectors; xᵢ and wᵢ are their entries at position i. The sum runs over all matching positions. The centered dot means dot product.
Norms and unit vectors|A norm measures a vector's size. Here we use the Euclidean norm: square the coordinates, add those squares, and take the square root. Dividing both coordinates by 5 gives u = (0.6, 0.8). Its squared length is 0.6² + 0.8² = 1.\n\nThe plot shows two vectors along the same direction, with different lengths. Euclidean distance|The Euclidean norm measures vector length. Orthogonality|Two vectors are orthogonal when their dot product is zero. For nonzero geometric vectors, this means they meet at a right angle. Their coordinates need not individually be zero: positive and negative products can cancel.\n\nOrthogonal directions let us change one component without changing the component along another. The zero vector has zero dot product with every vector, although it has no geometric direction. Orthogonal unit vectors are called orthonormal: they combine perpendicular directions with a standard length of one.|u · v = 0|Take u = (1, 2) and v = (−2, 1). Their dot product is 1(−2) + 2(1) = 0. Both lengths are √5, so they are orthogonal but not unit vectors.\n\nDividing each vector by its own length produces an orthonormal pair without changing the right angle. In the plot, edit the second vector's last coordinate from 1 to 2: the dot product becomes 2 and the right angle disappears.|Walking east does not move you north. Orthogonal directions separate two independent ways to move.|Are (2, 3) and (3, −2) orthogonal?|Yes; their dot product is zero ~ No; both have nonzero first coordinates ~ No; their lengths exceed one ~ Yes; every distinct pair is orthogonal|The coordinate products are 6 and −6, which cancel. Neither vector needs zero entries or unit length.|u and v are real vectors with the same number of coordinates. The centered dot is their dot product, computed by multiplying corresponding entries and adding. The equality is the test for orthogonality.

Span|The span of a set of vectors is the set of all linear combinations of them, allowing any real coefficients. It describes everything those building blocks can reach, rather than just one particular mixture.\n\nOne nonzero vector spans a line through the origin. Two nonparallel vectors in a two-dimensional plane span the whole plane; two parallel vectors still span only a line. The span always contains the zero vector. Adding a vector already in the span does not add any new reachable points.|span(u, v) = {au + bv : a, b ∈ ℝ}|Let u = (1, 2) and v = (2, 4). The combination u + 2v = (5, 10) is reachable. Every combination keeps the second coordinate twice the first, so (1, 0) is unreachable.\n\nReplace v by (0, 1). Now (1, 0) is obtained with coefficients 1 and −2, and any point in the plane can be reached. The plot samples integer coefficients from −2 to 2; it shows the pattern but is not the whole span, which also includes fractional and arbitrarily large coefficients.|Span is the complete territory you can reach with the movement controls you have, not the one destination currently selected.|Is (6, 9) in the span of the single vector (2, 3)?|Yes; it is three times that vector ~ No; a span contains only the original vector ~ No; both coordinates must match ~ Yes; every vector belongs to every span|A span permits all real multiples. Multiplying both entries by three produces the target.|u and v are the supplied vectors. a and b range over all real numbers, including zero and negatives. The braces mean the set of all resulting vectors.
Linear independence|A set of vectors is linearly independent if none can be built from the others. Equivalently, the only linear combination giving the zero vector uses all-zero coefficients. A set is dependent when at least one coefficient can be nonzero in a combination that cancels to zero.\n\nDependence means redundancy, not uselessness or numerical error. Removing a redundant vector does not change the span. Independence also makes the coefficients of a represented vector unique: two different recipes for the same result would subtract to a nontrivial zero combination. In a two-dimensional plane, at most two vectors can be independent: once two nonparallel directions span it, every extra vector is a combination of them.|au + bv = 0 implies a = b = 0|For u = (1, 0) and v = (0, 1), reaching zero forces each coefficient to be zero, so the pair is independent.\n\nAdd w = (1, 1). Now u + v − w = (0, 0) with nonzero coefficients, so the three-vector set is dependent. The target (2, 3) can be made as two u plus three v, or as one u plus two v plus one w. The extra vector adds another recipe, not another reachable direction.|Independent controls each add a capability; a dependent control can be reproduced by a combination of the others.|Are (2, 1) and (6, 3) linearly independent?|No; the second is three times the first ~ Yes; they are different vectors ~ Yes; neither is zero ~ No; all positive vectors are dependent|Subtracting three times the first from the second gives zero with nonzero coefficients, proving dependence.|This is the independence test for a pair of vectors u and v. a and b are real coefficients; the bold zero denotes the zero vector, while the zeros on the right are scalar coefficients.
Basis and dimension|A basis is a linearly independent set that spans the space being described. It offers enough vectors to reach every point in that space, without redundant vectors. Adding the usual coordinates and halving gives 3; subtracting and halving gives 1. This is one vector described with two coordinate systems, not two different vectors. The example's recovery rule is specific to this chosen basis.|A basis is a complete set of map directions. Matrix multiplication|For A of shape m × n and B of shape n × p, AB has shape m × p. Each entry is a row-column dot product.\n\nMatrix multiplication bundles many dot products into one operation. That produces two different output coordinates, 17 and 39, from the same input. Adding another input column would calculate both outputs for that input as well, without changing the transformation.|Each row submits a shopping list to each column of prices.|A is 2 × 3 and B is 3 × 4. Linear transformation|A linear transformation preserves vector addition and scalar multiplication. In finite dimensions, it can be represented by a matrix. Systems of linear equations|A system of linear equations asks for values that satisfy several linear relationships at the same time. Matrix rank|The rank of a matrix is the dimension of the span of its columns: how many independent output directions those columns provide. It is also the number of independent rows. Rank cannot exceed either the number of rows or the number of columns.\n\nRank counts independent information, not entries, nonzero values, or observations. A matrix-vector product can reach only its column span. A dependent column adds another possible recipe without adding a new output direction. This helps explain when systems of linear equations cannot identify unique unknowns.|rank(A) = dim(span(columns of A))|For A = [[1, 2], [2, 4]], the second column is twice the first. Its rank is 1. Every output has a second coordinate twice its first: this matrix cannot reach an arbitrary point in the plane.\n\nChange the bottom-right entry from 4 to 5. The columns are no longer multiples, giving rank 2. For this two-by-two case, compare the products of opposite corners: they are both 4 in the first matrix, but 5 and 4 after the edit. Unequal products mean rank 2; equal products mean rank 1 unless every entry is zero, when the rank is 0. The code uses this exact two-by-two test; large or noisy matrices need more careful numerical methods.|Rank counts how many genuinely different controls a machine offers, even if its panel contains many duplicate knobs.|What is the rank of [[2, 4], [3, 6]]?|1 ~ 2 ~ 3 ~ 4|The second column is twice the first, which is nonzero. There is one independent column direction.|A is the matrix. rank counts its independent columns; dim means dimension. The span contains every linear combination of the listed columns, including the zero vector.
Eigenvalues and eigenvectors|An eigenvector is a nonzero vector whose direction stays on the same line after a square matrix acts on it. Its eigenvalue gives the scaling, including a possible reversal.\n\nMost vectors mix directions under a transformation. Eigenvectors reveal special directions whose behavior is simpler: repeated applications keep the vector on one line and repeatedly multiply its scale. They help explain which patterns grow, shrink, or reverse in a repeated process.|Av = λv,   v ≠ 0|For A = [[2,0],[0,3]], A(1,0) = (2,0). Thus (1,0) is an eigenvector with eigenvalue 2. Artificial neuron|An artificial neuron turns several input numbers into one output. Each input is multiplied by a weight, which controls the size and direction of its contribution. A bias is then added.\n\nFor two inputs, x = (x₁, x₂) is the input vector and w = (w₁, w₂) is the weight vector. Match entries by position.
