## Scalar
A scalar describes one numerical value. Count separate components, rather than the number of digits used to write a value.
The sign tells you where a number lies relative to zero. It does not change how many numerical components it has.
The parentheses contain an ordered collection. Count each comma-separated numerical value, including repeated values if there are any.
Having no magnitude is different from having no numerical value. Consider how many components are needed to write zero.
Separate the operation's output from its inputs. Several readings can be combined into a single numerical result.
Distinguish the numerical value from the notation that tells you how to interpret a physical measurement.
A scalar is defined by having one numerical component. Sign, units, and whether the value is whole or fractional are separate properties.
The loss summarizes prediction quality. Look at the number of components returned, rather than how complicated its calculation was.
A minus sign and a decimal point belong to a number. A comma separating entries indicates additional numerical components.
Think about the type of result ordinary multiplication produces. It does not package the inputs into a list.
## Variable
Substitute the given input wherever x appears. Multiplication is performed before the final addition.
Follow the direction of the rule: one symbol is supplied, and the other is calculated from it.
Compare the rule at x and at x + 1. The fixed added constant cancels when you subtract the outputs.
Undo the addition before undoing the multiplication. Whatever operation you use must preserve equality on both sides.
An expression names a quantity; an equation asserts that two quantities are equal. Look for that assertion.
Check both restrictions: the number must be greater than zero and must have no fractional part.
Replace b with its signed value before adding. A negative input is not the same as subtracting the entire expression.
Distinguish the changing input and output from the numbers built into the rule itself.
A symbolic rule covers many possible inputs. Substitution lets you examine what the rule does in one particular case.
Equality lets you replace a symbol with an equal quantity. Apply that replacement to the first statement.
## Function
Check the outputs associated with each individual input. Different inputs sharing an output is a separate issue from one input being ambiguous.
For each input, inspect whether the rule specifies a unique output. Sharing an output across different inputs is allowed.
Separate what may be supplied to a rule from what the rule returns. The domain concerns the starting side.
Parenthesize the negative input when substituting. Squaring multiplies the entire signed value by itself.
The output need not change whenever the input changes. Check whether each input still receives a well-defined output.
Look for an input that makes the denominator invalid. A reciprocal requires a permitted division operation.
Work from the inside outward: evaluate g at the given input, then feed that result into f.
An inverse must decide which input produced an output. Think about what happens if several inputs share that output.
Limit attention to the IDs the table actually lists. Ask whether the assigned price is unambiguous for each one.
Compare how the output changes when an input is scaled. A squared input does not scale in the same way as the input itself.
## Units
Distance accumulates at the stated rate over the stated duration. Multiply the quantities and cancel compatible units.
Addition requires compatible physical dimensions. Different scales can be converted, but length and time cannot be added as lengths.
Centimetres are smaller than metres, so converting the same length to metres reduces the numerical value.
Keep the units in the fraction when dividing the quantities. The denominator describes the time over which distance is covered.
A measurement is a number together with a scale. Compare the physical length represented by one unit in each system.
Multiply the units as well as the side lengths. Area combines two independent length measurements.
The numerical value alone does not establish a physical quantity. Compare what one unit means in each case.
Convert both lengths into the same unit before adding. A kilometre contains a thousand metres.
An error has the target's units. Squaring the error also squares its units.
An input such as depth is ambiguous without a scale. A tool needs enough information to interpret the supplied number.
## Vector
Scalar multiplication applies the factor to every coordinate. It does not append the factor or multiply only one entry.
Add coordinates in matching positions. Combining all entries into one total loses the vector's structure.
Coordinates have positions and meanings. Compare the entries position by position, rather than as an unordered collection.
Dimension counts coordinates, including zero-valued coordinates. It does not count only positive or nonzero entries.
Apply the multiplier to every coordinate, including negative ones. The resulting vector retains its number of positions.
Subtract the second vector coordinate by coordinate. Keep the subtraction order, especially where the result changes sign.
Entrywise addition needs a partner for every coordinate. Check whether all positions can be paired.
The model associates each position with a feature. Swapping positions changes what the same numbers mean to it.
An additive inverse must cancel each coordinate separately when added to the original vector.
With one-based indexing, counting starts at the first entry. The subscript names a position, not the value to search for.
## Matrix
In Aᵢⱼ, the first subscript selects a row and the second selects a column. Apply them in that order.
Each inner list is a row. Matrix shape is written as the number of rows followed by the number of columns.
Each row has the stated number of columns. Count entries across all rows rather than adding the two dimensions.
A column is vertical: select the same position from each row. Do not copy one entire row.
A rectangular array requires every row to have the same length. Check for an incomplete or extra entry in a row.
Entrywise addition pairs entries at the same row and column. Both arrays must provide exactly those positions.
The scalar multiplier acts on every entry. Keep zero entries and negative signs in their original positions.
Being square concerns the two dimensions, not the values stored inside the array.
Use the stated orientation: rows identify samples and columns identify features. Read the entire selected row accordingly.
Locate each requested entry using row-then-column indexing, then add the two values. The subscripts are not factors.
## Tensor
Use the indices from left to right: select the outer block, then its row, then an entry within that row.
Each position in a shape tuple specifies one axis. The values in those positions specify axis lengths.
The total counts every combination of positions across the axes. Multiply the axis lengths rather than adding them.
Read the axis names in their stated order. The first index chooses among examples before selecting an image position.
Selecting one entry means fixing a position on every axis. Leaving an axis unspecified leaves a collection of values.
An axis is a direction along which entries vary. A single numerical value requires no coordinate positions to distinguish entries.
Reshaping changes the arrangement, not the number of stored entries. Compare the product of the proposed dimensions with the original count.
Calculate the total entry count before and after each proposed reshape. A different count requires adding or removing values.
Distinguish the number of positions in a shape tuple from the length specified at one of those positions.
Axis order determines which index selects a color channel and which selects a spatial position. Shape numbers alone may not explain that order.
## Summation
Expand the sum using every integer in the stated bounds. Square each index value before adding the terms.
The index controls how many terms appear, even when the term itself is constant. Write the constant once per index value.
Both endpoints are included. Start with the lower bound and list each successive integer through the upper bound.
A sum is a total; a mean also accounts for how many entries contributed. Use the number of indexed values.
Distributing multiplication across addition gives the same factor on each term. Compare that with scaling the completed sum.
The upper bound says where to stop, not which single value to return. Expand the full sequence of terms.
Substitute each listed coordinate and keep its sign. Opposite-signed terms may cancel before you finish the addition.
The index is a local label for visiting terms. Check whether the actual values being added change when that label changes.
Read the parentheses carefully. They determine whether squaring acts on individual entries or on an already-computed total.
Include the zero-indexed term and both endpoints. The number of included positions is not simply the upper bound.
## Dot product
Multiply coordinates in matching positions and then combine those products. Do not multiply the coordinate sums.
Form the coordinatewise products first. Keep the negative sign when combining the products.
After the matching products are formed, they are summed. Consider whether any coordinate list remains in the output.
Pair each coordinate with itself, then add the products. This is a squared length, not the length itself.
Use x·y = ||x|| ||y|| cos θ. The nonzero-vector assumption lets you reason about the angle from the cosine.
A zero coordinate contributes no product. Match positions carefully before adding the contributions.
Every coordinate on one side needs a corresponding coordinate on the other. Check whether all positions can be matched.
For real numbers, each paired multiplication can be reversed without changing its value. The sum contains the same pairs.
The changed factor appears in every coordinate product. Distribute it through the sum to see its overall effect.
Match each purchased quantity with its own price, then combine the item-level amounts. Do not add quantities and prices separately.
## Matrix multiplication
Check the inner dimensions for compatibility. Then count the output's rows from the left matrix and columns from the right.
The output entry comes from pairing the row's entries with the column's entries, multiplying, and summing.
In this order, each row of the left matrix must pair with a column of the right matrix. Compare their lengths.
Matrix products represent ordered operations. Reversing them can change the effect or even make the product undefined.
An identity map performs no change to its input. Check how that property carries through a compatible product.
An output's row comes from the left operand and its column from the right. Each output combines their matching entries.
The inner dimensions match. Use the left operand's row count and the right operand's column count for the result.
Compute a dot product for each output row. The zeros remove the cross-coordinate contributions.
An output of a matrix product combines several input pairs. Elementwise multiplication keeps each position separate.
The operation nearest x happens first. Write the second transformation around the result of the first.
## Transpose
Transposition exchanges row positions with column positions. Apply that exchange to the two dimensions.
Read each original column as a row of the result. Keep the order within each column.
The first transpose swaps the indices. Apply the same index swap again and track where an entry ends up.
Transposition rearranges existing entries. It does not create new positions or discard values.
A row matrix has one row. After exchanging the axes, consider which dimension becomes one.
Compare every off-diagonal entry with the entry obtained by swapping its indices. A square shape alone is insufficient.
Swap the row and column subscripts. The entry's value stays the same while its position changes.
Transposing a composition reverses the order of its factors. Check the resulting shapes as well as the symbols.
Undoing a transformation requires an inverse. Swapping rows and columns only gives an inverse for special matrices.
A diagonal position has equal row and column indices. Track what swapping those equal indices does.
## Linear transformation
Test preservation of addition and scaling. A fixed offset or a nonlinear power can break those properties.
Use preservation of scaling with a zero multiplier. A linear map cannot introduce a fixed offset at the origin.
Evaluate the rule at zero and inspect the added constant. A straight-line graph alone does not establish mathematical linearity.
Linearity lets a scalar factor pass through the map. Apply it to the given transformed vector.
For a linear map, transform the two vectors separately and add those outputs coordinate by coordinate.
Check that the operation fixes the origin and respects scaling and addition. Moving every point by an offset breaks this.
A matrix can have fewer rows than columns. Think about what those dimensions mean for the output vector.
Fixing the origin checks only one consequence of linearity. A nonlinear function can also pass through the origin.
Substitute the coordinates into each output expression independently. The result still has two ordered components.
Distribute matrix multiplication across a sum and pull scalar factors outside. These properties describe what the map preserves.
## Euclidean distance
Subtract matching coordinates, square the differences, and add. The final distance also requires a square root.
Check which coordinate actually changes. An unchanged coordinate contributes zero to the squared separation.
Subtract the vector from itself coordinate by coordinate. Then apply the usual distance calculation.
Exchanging the points reverses each difference's sign. Consider what happens when those differences are squared.
A norm measures distance from the origin. Square both signed coordinates before adding and taking the square root.
Distance combines coordinate differences. Changing one feature's scale changes the influence of differences along that coordinate.
The multiplier affects every coordinate. Track its effect through squaring, summing, and the final square root.
This asks for squared distance. Sum the squared coordinate differences and check whether a square root is still requested.
For one coordinate, distance ignores which point lies to the left. Your expression must stay the same when x and y are exchanged.
The squared differences are nonnegative, and distance uses the nonnegative square root of their sum.
## Eigenvalues and eigenvectors
Multiply the matrix by the stated vector, then compare the output with the original vector. Look for a common scale factor.
The defining equation must identify a direction and its scale factor. Test whether the zero vector distinguishes any particular factor.
Matrix multiplication is linear. Pull the scalar multiplier outside before applying the given relation for Av.
Separate the sign of a real scale factor from its absolute magnitude. They affect orientation and length differently.
Substitute the eigenvalue into Av = λv. Consider the output of multiplying a nonzero vector by that factor.
Compute the transformed vector and compare both component ratios with the original. An eigenvector requires a common ratio.
An identity matrix preserves every vector. Compare that output with the eigenvalue equation for a nonzero vector.
Real entries do not ensure real eigenvectors in every direction. Consider a planar rotation or a defective matrix.
Apply A once, then apply it to that result. Linearity lets you pull the first scale factor outside.
Symmetry supplies stronger guarantees than simply being square. Consider the eigenvalues' field and the geometry of the eigenvectors.
## Singular value decomposition
Compare the error caused by dropping each diagonal component. Squared entrywise error penalizes dropping a larger component more heavily.
SVD separates input and output directions, which need not have the same dimension. Do not impose the square-matrix restriction from eigendecomposition.
Singular values describe scale magnitudes. Directional signs can be represented by the associated singular vectors instead.
Each retained singular component contributes at most one independent direction. Count the directions that can remain.
Identify the component that was discarded. Its contribution to squared entrywise error is the square of its value.
A zero singular component carries no independent direction through the matrix. Count only the components that remain active.
An eigenvalue can include a sign or even be complex. Singular values summarize magnitudes under a different factorization.
Apply the factors from right to left. The first rotation changes the input's coordinates before the singular-value scaling.
The approximation minimizes a specified numerical reconstruction error. That objective need not match the needs of a later task.
Centering removes the feature mean. Then relate the input directions of the data matrix to directions of maximum variance.
## Probability
List the equally likely die faces that satisfy the strict inequality. Divide their count by the total face count.
A probability ranges from impossibility to certainty. Check each value against both ends of that range.
An event and its complement exhaust all possible outcomes without overlap. Their probabilities must add to certainty.
Independence lets you multiply the probabilities of the required outcomes. Count sequences, rather than only the outcome types.
Mutually exclusive, exhaustive outcomes partition all possibilities. Subtract the known probabilities from the total probability mass.
A high probability leaves room for other outcomes. A single trial does not have to match the more likely outcome.
For disjoint events, no outcome belongs to both. Combining them therefore requires no overlap correction.
Think about an outcome in both events. Adding the two event probabilities includes it once through each event.
Counting treats every outcome as contributing the same probability mass. Check what must be true for that assumption to hold.
An expected count describes an average over repeated sets of trials. Individual sets can fluctuate around that average.
## Conditional probability
Conditioning changes the population you count within. First restrict attention to the deep samples, then count hot samples in that group.
Use the joint probability as the numerator and the probability of the condition as the denominator.
The event after “given” restricts the reference group. Evaluate the color frequency within that restricted group.
Reversing the condition changes the denominator and reference population. Sharing the same joint event does not make the fractions identical.
Independence means learning that one event occurred supplies no information about the other event's probability.
Write out the elementary ratio for conditioning. Check whether its denominator permits an ordinary division.
The total sample count is not the denominator after conditioning. Count noisy samples within the deep subset.
Test sensitivity describes one conditional direction. Reversing it also requires the condition's prevalence and the false-positive behavior.
Rearrange the conditional-probability ratio to recover the joint probability. Keep the probability of the condition as a factor.
Conditioning describes an association in observed probabilities. It does not specify what would happen if you intervened.
## Bayes’ theorem
Restrict the denominator to everything flagged, including good parts. Then count defective parts within that flagged group.
Place the quantities on a timeline: belief before observing evidence, evidence under a hypothesis, and belief after the update.
The condition specifies which hypothesis is assumed. The probability then concerns the observation you would see under that assumption.
Multiply the prior by the likelihood, then normalize by the overall evidence probability. Do not reverse the conditional direction.
Compare the evidence's likelihood under the competing hypotheses. A shared likelihood factor cancels when probabilities are normalized.
Count how many tested people or objects come from each group. A small error rate applied to a large group can matter greatly.
Each conditional probability uses a different reference population. Bayes' theorem accounts for those populations rather than swapping the notation.
The elementary formula uses the evidence probability as a denominator. Check whether ordinary division is defined for the stated value.
The condition is being flagged. Combine all flagged parts for the denominator, then identify defective ones within that group.
An updated belief summarizes the evidence already processed. A later update should add new evidence without counting the old evidence twice.
## Expected value
Weight each possible payout by its probability, then add. The probability is a multiplier, not the amount paid.
List the two coin outcomes and weight each payout by its chance. Do not assume the winning payout occurs every time.
An expectation is a probability-weighted average. An average need not be one of the outcomes being averaged.
With a constant, every possible observation has the same value. Averaging identical values does not introduce variation.
Expectation distributes over addition and fixed scalar multiplication. Apply those operations to the stated expectation.
Linearity of expectation concerns sums. Independence becomes relevant to other identities, such as factoring an expectation of a product.
Net gain includes both the payout and the price paid to participate. Treat the cost as a certain subtraction.
An expected value must reflect both outcome sizes and their relative chances. Counting outcomes alone ignores their values.
The average does not specify how widely outcomes vary. Compare a guaranteed return with a mixture of gains and losses.
The outcomes are not equally likely. Multiply each by its own probability before combining them.
## Variance
Find the mean, subtract it from each value, and square those deviations before averaging. Do not stop at the range.
Variance measures deviations from the mean. Compare each observation of a constant with that same constant's mean.
Variance and standard deviation are different quantities. One is the square of the other.
Shifting all observations also shifts their mean by the same amount. Compare the deviations before and after the shift.
Scaling multiplies every deviation, and variance squares those deviations. Track the multiplier through the square.
Every squared deviation is nonnegative. Averaging those quantities cannot produce a value below zero.
Compute the mean of the two equally likely values, then average their squared distances from that mean.
Variance squares the original units; standard deviation reverses that squaring with a square root.
Deviations on opposite sides of the mean have opposite signs. Their signed average does not preserve their distances.
Compare the distances of each pair's entries from that pair's mean. The larger overall location is not what measures spread.
## Covariance and correlation
Center each coordinate by its own mean, multiply the paired deviations, then average those products over the two equally likely pairs.
Examine the sign of a product when one deviation is positive and the other negative. Covariance averages those paired products.
Pearson correlation normalizes covariance by both standard deviations. The resulting measure of linear association has bounded magnitude.
Normalize covariance by the product of the two standard deviations, rather than their sum.
Only one factor in each paired-deviation product is scaled. The centering step scales that deviation by the same amount.
Adding a constant to a variable also adds it to that variable's mean. Compare the centered values.
Pearson correlation measures linear association. A nonlinear dependence can have a vanishing average product of centered values.
Write the correlation denominator as the product of standard deviations. A constant has no variation around its mean.
Negating one variable reverses its centered deviations but leaves its standard deviation's magnitude unchanged.
An association can arise from a common cause, selection, or other mechanisms. Correlation alone does not distinguish them.
## Monte Carlo estimation
A sample estimate of an expectation averages the observed rewards. Do not return their total or just the most frequent value.
An unweighted sample mean reflects the distribution that generated its samples. More draws do not change which distribution that is.
Apply the square root to the sample-size factor before considering the inverse relation for standard error.
Represent a success as one and a failure as zero. Their sample mean estimates the success probability.
Sampling error and model error are different. Additional draws can estimate a flawed simulator's predictions more precisely.
A seed controls the pseudorandom sequence under a particular implementation. It does not establish that the model is correct.
Repeatedly seeing similar fluctuations supplies less independent information. Raw sample count can overstate the effective sample size.
Divide the sample standard deviation by the square root of the independent sample count, not by the count itself.
The estimate depends on sampled outcomes. Another set of draws can produce a different average even under the same model.
Estimating an event rate requires observing that event. Consider how many occurrences a finite simulation is likely to contain.
## Exponential and logarithm
A natural logarithm asks which power of e produced its input. Apply the inverse relationship before calculating any decimal approximation.
Ask which exponent applied to the stated base produces the argument. Multiplying the base by an exponent is a different operation.
Use the exponent rule for bᵃ divided by itself, with a permitted nonzero base, to understand the zero exponent.
Ask what power of e yields the logarithm's argument. A logarithm returns an exponent, not its input.
Logarithms convert multiplication of positive arguments into an operation on their exponents. Check the product rule rather than the power rule.
A negative exponent takes a reciprocal. First evaluate the corresponding positive power, then invert it.
The real natural logarithm inverts the positive-valued exponential function. Check which proposed input falls outside that range.
Each doubling multiplies the current amount again. Repeated multiplicative changes do not add their factors.
The exponential and natural logarithm are inverse operations. Track the exponent through that pair of operations.
Multiplying many small probabilities can underflow in finite precision. Consider whether an equivalent accumulation avoids that repeated shrinking.
## Derivative
Differentiate the expression before substituting the location. For a power, reduce the exponent and bring down its original value.
A derivative measures output change per input change. Check how much a constant output moves as its input changes.
The slope of this straight line is fixed. Distinguish the coefficient of x from the function's value at x.
Use the local approximation Δf ≈ f′(a)Δx with a small positive input change. Track the sign of the product.
First derive the slope function for the square. Then evaluate that slope at the requested input.
A stationary point can be a maximum, minimum, or neither. Its slope alone does not compare it with every other point.
A derivative is obtained from slopes as the interval shrinks toward the point. A secant uses separated endpoints.
Keep units in the ratio of output change to input change. Here the input variable is time.
Use the local linear approximation: output change is approximately slope times the small input change.
Apply the power rule before substituting the input. The requested quantity is slope, not the original cubic value.
## Integral
For a constant rate, accumulation is the rate multiplied by the duration. Keep the units through the multiplication.
The graph is a rectangle with constant height over the integration interval. Use the interval's width, not merely a bound.
Signed velocity distinguishes opposite directions. Its contributions accumulate with their signs, unlike total distance traveled.
Integration bounds specify the direction of accumulation. Reversing that direction changes the orientation of the signed total.
Identical bounds leave no interval over which to accumulate. A nonzero integrand alone does not create interval width.
Multiply the rate's units by the integration variable's units. The per-second factor cancels the elapsed seconds.
The graph rises linearly from the origin. Compute its triangular area or evaluate an antiderivative at both bounds.
A function value supplies a height. An accumulated contribution also needs the width of the piece it represents.
A definite integral is signed accumulation. Regions on different sides of the axis can contribute opposite amounts.
Increasing the upper endpoint adds a thin slice of accumulation. The fundamental theorem relates its local rate to the slice's height.
## Gradient
Differentiate the loss with respect to each coordinate separately, then evaluate both derivatives at the given point.
Apply the power rule coordinate by coordinate. Substitute the negative coordinate with its sign intact.
A partial derivative isolates one coordinate's effect. Do not let other independent input coordinates change during that calculation.
Each parameter has its own partial derivative. The scalar output's size does not determine the number of gradient entries.
The directional derivative is a dot product with the gradient. Compare directions of equal Euclidean length.
Each partial derivative treats the other variable's term as constant. Differentiate the two linear terms separately.
Stationarity alone does not classify a point. Consider a surface that curves upward in one direction and downward in another.
Approximate the loss change by the partial derivative times the small parameter change. The product's sign determines the local trend.
A derivative measures change per unit of its coordinate. Coordinate units and scaling affect the numerical magnitude.
When differentiating a product of independent inputs with respect to one input, hold the other input fixed, then substitute the point.
## Hessian and curvature
Take another derivative of each gradient component. Terms depending on only one variable do not produce cross-variable curvature.
Differentiate twice and preserve the sign of the negative squared term. The two coordinate directions have different curvature signs.
At a stationary point, inspect whether small moves can increase the function in one direction and decrease it in another.
Positive definiteness gives upward second-order curvature in every nonzero direction. The conclusion is local to the stationary point.
When second-order terms vanish, higher-order terms may still determine the behavior. Compare x⁴ with −x⁴ at the origin.
Differentiate the fourth power twice before substituting the input. Evaluating the first derivative answers a different question.
A Hessian contains one derivative for each ordered pair of input coordinates. Count the positions in that square array.
Equality of mixed derivatives has regularity assumptions. Smoothness nearby matters, not merely writing the derivative symbols in either order.
An affine function has constant first derivatives. Check what happens when those constants are differentiated again.
The same step size acts in every direction. Strong curvature can cause overshooting while weak curvature permits little progress.
## Chain rule
Differentiate the outer square and multiply by the inner linear derivative. Evaluate the composed factors at the given input.
The outer function sees the whole parenthesized expression as its input. Differentiate it and then include the inner derivative.
Treat 2x as an intermediate variable. Its rate of change with x must multiply the outer derivative.
Along a composition, changes pass through successive stages. Combine the rates multiplicatively rather than adding them.
Differentiate sine with respect to its argument, then account for how quickly the argument changes with x.
The composition's derivative multiplies its inner and outer factors. Track the effect of a vanishing factor with the stated finite assumption.
A weight can affect the loss through several intermediate quantities. Each stage contributes a rate of change along the dependency path.
The exponential differentiates with respect to its entire argument. Include the derivative of that argument with respect to x.
Each stage scales the change received from the previous stage. Follow the complete path before combining its factors.
A variable may contribute through more than one route. Compute each path's effect before combining the contributions to the total change.
## Optimization
The unconstrained best point may be forbidden. Compare feasible points by how close they can get to the square's center.
Distinguish the location where the best value is reached from the value of the objective at that location.
A square cannot be negative. Identify the input that makes the quantity inside the square vanish.
A good objective value is not sufficient if the choice violates the allowed conditions. Check the permitted set first.
Constraints can exclude the unconstrained optimum. The best allowed point can occur where further improvement would leave the permitted region.
Check whether the goal prefers larger or smaller objective values. Maximizing reward reverses the preference used when minimizing loss.
Local optimality compares nearby choices. It does not evaluate distant regions of the feasible set.
Evaluate the objective for the allowed inputs, or examine whether it rises or falls as x increases.
Different inputs can produce the same objective value. Uniqueness requires additional properties beyond the existence of an optimum.
Performance can mean accuracy, speed, cost, or something else. An optimizer needs a stated criterion for comparing choices.
## Lagrange multipliers
Use the constraint to fix the sum. For this symmetric squared objective, compare an unequal allocation with an equal allocation.
The constraint limits where candidates may lie. A point with an attractive objective can still be excluded.
Write the equality in the form g = 0 before multiplying it by λ. Keep the sign convention stated in the question.
The derivative equations balance changes; the original constraint still decides whether a candidate is permitted.
Under a fixed sum, shifting away from equal coordinates increases this symmetric sum of squares. Use the required total.
Stationary conditions produce candidates, not a complete classification. Check the objective and feasible behavior around each candidate.
An equality multiplier balances gradients. Unlike multipliers for certain inequality conventions, it has no general sign restriction.
Write both parameter derivative equations and the constraint. Solve for the coordinates before using either derivative equation to find λ.
Feasible tangent moves must leave the constraint unchanged to first order. At stationarity, none of those moves can improve the objective to first order.
Inequalities can be active or inactive and introduce additional conditions. The equality-only equations omit those cases.
## Gradient descent
Compute the learning-rate-scaled gradient, then subtract that step from the current parameter. Do not return the step alone.
Write the subtraction explicitly before replacing the gradient with its signed value. Subtracting a negative step changes direction.
The learning rate multiplies the gradient in the update. Track what happens when that multiplier vanishes.
The gradient describes local behavior. A large move can leave the region where that direction gives improvement.
The gradient points toward local increase. Inspect the sign used before the gradient term in each update.
Differentiate the squared loss at the current parameter, multiply by the learning rate, and subtract from the current value.
Plain gradient descent uses the current gradient directly. It has no momentum or random perturbation to supply another step.
Nonconvex losses can contain several stationary regions. A local descent rule does not compare all possible minima.
Hold the gradient fixed and change only its multiplier. Compare the resulting step lengths, not the resulting parameter values.
The update needs local information about how the objective changes with its parameters. The loss value alone does not supply a direction.
## Dataset and features
Use one row for each sample and one column for each feature. Matrix shape records these counts in that order.
Follow one column downward through the rows. The sample changes while the feature associated with that position stays fixed.
The target is the quantity the model is meant to predict. Distinguish it from measurements available before making that prediction.
Each sample supplies the same stated number of entries. Count entries across all samples using multiplication.
The same number can represent different measurements or scales. Names and units establish the meaning expected by the model.
Ask whether the input would actually be available at the prediction time. Including the outcome being predicted defeats that boundary.
Supervised learning requires paired inputs and desired outputs. Those outputs need not be continuous measurements.
Use the table's stated organization. One example pairs the inputs of a particular observation with its corresponding outcome.
The model learned a meaning for each input position. An unnoticed permutation changes the interpretation of its inputs.
More observations can reduce sampling noise while preserving the same systematic measurement error. Size alone does not repair bias.
## Linear regression
Substitute the input into the fitted rule. Multiply by the slope before adding the intercept.
The negative intercept is added after the slope-times-input term. Keep the subtraction sign when evaluating the rule.
Set the input to zero in the prediction equation. Observe which part of the expression remains.
The slope measures output change per unit input change. Its sign determines the direction of that change.
Pair each feature with its own weight, sum those products, and then include the bias.
Regression predicts a numerical magnitude. Distinguish that from choosing a label or discovering unlabeled groups.
A fitted line describes an association in the data. It does not specify what an intervention would do.
If the feature's multiplier vanishes, varying the feature no longer contributes to the prediction.
Residuals show what is left after the prediction. Systematic remaining structure suggests the fitted rule has not captured everything useful.
Observed fit tests only the supported input region. The relationship outside that region may behave differently.
## Mean squared error
Square each error separately, then average those squares. Squaring the mean error is a different operation.
The zero error still contributes an example to the denominator. Average over both observations after squaring.
Squaring removes the sign of an error. Compare the magnitudes before considering which direction the prediction missed.
MSE averages nonnegative terms. Consider what must be true of every term for their average to vanish.
The scale factor acts on each error before squaring. Track that factor through the square and the average.
The contribution is the square of the error, not the error itself. Larger mistakes grow disproportionately under this loss.
The extra operation in RMSE restores the original error units. Distinguish an average of squares from its root.
First subtract targets from matching predictions. Square the resulting errors and average over the two examples.
Training error measures fit to examples already used in learning. New wells can contain different patterns or noise.
Converting a length changes each numerical error by the conversion factor. MSE then squares that factor.
## Supervised learning
Look for training inputs paired with the desired outputs. Merely grouping similar inputs does not supply that pairing.
The learning procedure needs a reference outcome against which to compare each prediction, not just a collection of inputs.
Classification learns to predict categories from labeled examples. Look for a task with both examples and class labels.
Separate values fitted from examples from fixed data and settings that govern the training procedure.
Good fit to already-seen examples can include memorization. Evaluation needs evidence about performance beyond those examples.
Training treats labels as the reference signal. Systematic mistakes in that signal can teach an undesirable association.
Distinguish the stage that adjusts a model from the stage that applies its learned rule to an input.
Targets may come from measurements, recorded outcomes, or other processes. The learning setup depends on pairing, not who created each label.
A model evaluated with unavailable future information is solving an easier problem than the one it will face in use.
The association between the example and its desired output matters. A separate unpaired list of outcomes does not define those training pairs.
## Parameter and hyperparameter
Separate values directly updated by the model's fitting procedure from settings that control how those updates are made.
Gradient descent updates quantities inside the parameterized model. Compare those with choices made about the training procedure.
Ask which quantity controls the size or organization of training steps rather than being fitted as part of a prediction rule.
A bias can be adjusted to reduce loss just as a weight can. Its name does not place it outside the fitted model.
Model-selection decisions need feedback that is separate from parameter fitting while leaving the final evaluation untouched.
Changing how many examples contribute to one update changes the training procedure, not an individual learned coefficient.
Hyperparameters can be searched over by another procedure. They need not remain fixed by a human's first guess.
Identify the coefficients that fitting adjusts in this prediction equation. The input and observed target play different roles.
The architecture determines which parameters exist before they are fitted. Distinguish choosing that structure from learning its weights.
The final coefficients do not describe every choice made during training. Conversely, training settings do not specify the learned coefficients.
## Training, validation and test
Choosing an update setting is model selection. It needs a comparison set while preserving a separate final evaluation.
Fitting weights directly uses examples to reduce the training objective. Distinguish fitting from model selection and final assessment.
Comparing architectures is a model-selection step. Reserve a separate split whose results do not guide that choice.
If evaluation results change the model choice, that evaluation has joined the selection process. An independent final estimate comes afterward.
Check membership at the example level. Different filenames or shuffled ordering alone do not establish separation.
Samples from one well can share geology and measurement conditions. Splitting their rows can make held-out data less independent than intended.
Estimating preprocessing values uses information from the observations. Keep held-out examples out of that fitting step.
Repeated selection adapts decisions to the observed scores. A dataset used that way no longer provides an untouched assessment.
Match the information boundary of deployment. Future observations should not influence a model intended to predict them from the past.
A test score is conditional on the sampled data, metric, and procedure. Extending it to other settings requires additional evidence.
## Data leakage
To test a genuinely unseen well, prevent any measurements from that well from influencing training or preprocessing.
Preprocessing can learn from data even without labels. A held-out distribution should not influence the fitted transformation during evaluation.
Ask whether the feature exists at the moment the prediction is made. Later outcomes cannot be available to a real-time predictor.
Different windows can contain many of the same raw observations. Distinct row IDs do not make them independent examples.
Decide the held-out groups before constructing examples that could share their measurements across the split.
Using a test score to revise choices makes those choices depend on the test. That weakens its independence as a final evaluation.
Feature presence can reveal an outcome even without storing the outcome's name. Inspect when and why the field is populated.
Information about a target can remain in proxies, duplicated records, preprocessing statistics, or future measurements.
Availability is a time-dependent property. A feature in an eventual record may be absent when the model must act.
Unusually strong results deserve extra scrutiny when training and test examples share underlying information. A score alone does not identify the cause.
## Normalization
Subtract the fitted mean first, then express that deviation in units of the fitted standard deviation.
Keep the sign of the difference from the mean before dividing by the positive scale.
A standardized coordinate measures displacement from a fitted reference. Identify the original value that produces no displacement.
Check the denominator before applying the transformation. A constant feature needs special handling instead of ordinary division by its scale.
The model expects the coordinate system used during fitting. Re-estimating it on each deployment sample changes the input meaning.
Centering and rescaling adjust location and spread. They do not remove skewness or force a particular distribution shape.
Distance squares and combines coordinate differences. Large numerical scales can dominate that combination even without greater relevance.
Undo division by multiplying by the fitted scale, then undo centering by adding the fitted mean.
Centering a value by itself discards the difference you want to measure. The reference must be consistent with model training.
The sign indicates which side of the fitted mean the value lies on. The magnitude counts fitted scale units.
## k-nearest neighbors
Unweighted neighbor regression averages the selected targets. Do not return their sum or the nearest target alone when k is larger than one.
The selected examples already carry class labels. Think about how several labels can be combined into one class decision.
First compare input distances to identify the selected neighbor. Then use that neighbor's target, not its input coordinate.
Distance uses numerical differences, so units and scales affect which neighbors appear closest. Equal relevance does not imply equal raw magnitudes.
With only one selected example, there is no averaging or voting across other neighbors to soften that example's error.
Using more neighbors averages over a wider region. That can reduce sensitivity while blurring local changes.
Count the selected labels with equal weight. The nearest example alone does not decide a majority vote with several neighbors.
Closeness is computed in the supplied feature space. Differences in uninformative coordinates can outweigh useful similarities.
The neighbor count influences the model's behavior and is a selection choice. Keep the final test out of that choice.
Storing examples postpones much of the work until prediction. A query must still identify nearby training examples.
## Decision trees
Evaluate the split condition with the query input. Follow only the branch whose condition holds.
After routing ends, the leaf must supply an output. In regression, that output is derived from the targets assigned to that region.
A mean prediction combines all targets in the leaf equally. Divide the total by the number of observations.
Many successive splits can isolate individual observations. That flexibility can capture accidental details of the training sample.
An axis-aligned boundary acts on one coordinate at a time. It does not require a weighted combination of all features.
Impurity concerns the distribution of labels inside a node. A node's size alone does not tell you how mixed those labels are.
For a pure node, one class has all the probability mass. Substitute that distribution into the stated expression.
Choosing thresholds is part of fitting the prediction rule. Held-out outcomes must not influence that fitted rule.
A small input change can cross a split and reach a different leaf. Compare the predictions stored in those leaves.
A split is chosen for predictive usefulness under the training objective. It does not establish the effect of an intervention.
## Overfitting
Compare improvement on seen examples with behavior on held-out examples. Diverging trends suggest the extra fit is not transferring.
Look for a growing mismatch between fitting the training sample and predicting examples excluded from that fitting.
A model may fit sample-specific details or encounter different deployment conditions. Training fit alone does not test either risk.
Stopping time is a model-selection decision. Use held-out behavior while keeping a final test separate.
Check whether the model is struggling even on the examples used for fitting. That differs from fitting them well but failing elsewhere.
Representative additional examples can make accidental patterns less persuasive and expose variation missing from a narrow sample.
Compare test error with training error using a difference in the stated direction. A ratio answers a different question.
A gap can also reflect distribution differences, preprocessing errors, or sampling variation. Inspect the evaluation setup before assigning a cause.
A flexible model has more ways to match the observed sample. Some of those ways capture noise instead of transferable structure.
The evaluation should hold out the unit you want to generalize to. New rows from a familiar well may not test new-well performance.
## Regularization
In the objective, λ scales the weight-dependent term. Hold the weights fixed and inspect which contribution becomes more influential.
The squared L2 norm sums squared coordinates. It does not take the final square root used by the ordinary L2 norm.
The penalty's contribution is multiplied by its strength. Evaluate that multiplication before considering its effect on fitting.
An overly strong preference for a restricted model can prevent it from capturing useful patterns, even in training.
First weight the penalty by λ, then combine it with the data-fit loss. Neither part replaces the other.
Treat λ as fixed and apply the power rule to w. The derivative is with respect to the weight, not the penalty strength.
A squared-magnitude penalty treats all coefficient sizes continuously. Counting how many coefficients are nonzero is a different objective.
Penalty strength affects model selection. Compare held-out performance while reserving a separate final assessment.
The effect depends on the data, model, and selected strength. A method intended to improve generalization is not a universal guarantee.
Rescaling an input can be offset by an inverse change in its weight. The predictions can match while the coefficient penalty changes.
## Random forests
Equal weighting combines the tree outputs through an average. Count each tree once in the denominator.
Averaging is more useful when errors are not all identical. Random construction encourages trees to use somewhat different evidence.
Check whether a drawn observation remains eligible for another draw. That distinction allows duplicates and leaves some observations absent.
Restricting candidate features prevents every tree from always choosing the same dominant predictors at every split.
Treat each tree's probability as one equally weighted estimate. Average the probabilities rather than multiplying them.
If every component makes the same error, their average retains that shared error. Diversity matters for variance reduction.
Bootstrap sampling repeats some training records and omits others. Identify the records that did not influence this particular tree's fitting.
Consider the dependency between fitted trees. Some ensemble methods require a previous model's errors before fitting the next component.
More trees can stabilize an average while retaining systematic errors or a mismatch between training and deployment populations.
Complexity alone is not evidence of usefulness. A common evaluation lets you compare actual predictive value on the same task.
## Gradient boosting
Scale the new learner's output by the learning rate, then add that correction to the current prediction.
For squared-error residual fitting, subtract the current prediction from the observed target. Preserve the order of that subtraction.
Each added component is fitted with reference to the current ensemble's behavior. Changing earlier predictions changes that fitting problem.
The learning rate controls how much of the proposed correction is included. It does not directly set the learner's prediction.
Keep the new learner's negative sign when scaling its contribution. Add the signed correction to the old prediction.
Additional stages may continue fitting training details after held-out performance stops improving. Stopping time is chosen from that held-out behavior.
Gradient boosting follows the chosen loss's negative gradient. The familiar residual expression is specific to particular losses.
The ensemble builds a prediction from many limited components. A component need not solve the whole problem accurately by itself.
Sequential correction can keep adapting to incidental training details. The ensemble still needs appropriate capacity control and evaluation.
Compute the scaled update and the resulting prediction first. Then subtract that prediction from the target to find what remains.
## Class imbalance, precision and recall
Recall uses all actual positive cases as its reference group. Include both detected and missed positives in the denominator.
Precision asks about cases predicted positive. Include correct alarms and false alarms in that reference group.
Count the correct predictions for the majority class, then divide by all examples. Accuracy weights each example equally.
Actual positives exist, but the rule never predicts one. Examine the detected-positive numerator of recall.
The “positive” part describes the prediction; “false” says it disagrees with reality. Track both labels separately.
Lowering a fixed-score threshold adds possible positive predictions rather than removing them. Consider the already-detected positives.
Distinguish the fraction of real positives found from the fraction of alarms that are justified. They use different denominators.
Write the denominator in terms of all positive predictions. The raw ratio requires that reference group to be nonempty.
Substitute both metrics into the stated harmonic-mean formula. Keep the denominator as their sum.
Resampling learns or changes information from the data. Keep validation observations outside that operation in every fold.
## Probability calibration
Compare the predicted probability with the observed fraction of positives in this group. Do not compare it only with the positive count.
The observed frequency is the positive count divided by the group size. The predicted probability is a separate quantity to compare afterward.
A probabilistic forecast permits either outcome. Calibration concerns frequencies across comparable predictions, not certainty in one case.
Ranking depends on order; calibration depends on numerical probability values. Changing those values can preserve order while changing calibration.
Group similar forecasts and compare their numerical probabilities with what actually happened in those groups.
Training predictions can reflect overfitting. A calibration mapping should see behavior representative of predictions on examples not used for fitting.
Calibration is assessed relative to a population and conditions. A changed relationship or prevalence can invalidate that assessment.
For a binary outcome, Brier loss is the square of the difference between the predicted probability and the outcome indicator.
Compare the forecast level with the group's observed positive fraction. Check the direction of the discrepancy before labeling it.
An observed fraction based on very few cases can move substantially with one additional outcome. That variability can mimic poor calibration.
## Causal inference
The requested contrast subtracts the control group's mean from the treatment group's mean. Preserve that order.
Look for a prior variable that can create an association by affecting both which treatment is received and the eventual outcome.
Randomization breaks systematic links between assignment and preexisting characteristics on average. It does not make every realized group perfectly identical.
An individual is observed under the condition actually received. The causal comparison also needs an outcome under a condition not received.
Prediction estimates observed associations. An intervention asks what changes when an action is imposed, which needs additional assumptions or design.
Look for a factor that plausibly changes both activities. Correlated outcomes do not have to cause each other.
Follow the specified treatment-minus-control direction, even when the treatment group's mean is smaller.
A post-treatment variable may transmit part of the effect. Holding it fixed can change which causal effect the comparison measures.
The target contrasts two potential conditions over a defined group. It is not merely the observed difference between any two selected groups.
Observed groups may differ for reasons besides treatment. A causal interpretation must justify how the design handles those differences.
## Domain shift and adaptation
An absolute percentage-point gap subtracts the two percentages. A relative percentage change uses an additional division.
The deployment distribution can change when the measurement process changes, even if the task and feature names stay the same.
Distinguish a change in how frequently inputs occur from a change in the label relationship conditional on those inputs.
A small target sample may be unrepresentative or insufficient. Updating weights does not establish performance on unseen target examples.
Validation should resemble the situation in which predictions will be used, including the relevant population and information available.
A single average combines potentially different environments. A large group with good results can hide a smaller group's poor results.
A changed input mean is evidence of a distribution difference. Its effect on predictions depends on the model and target relationship.
Using target examples to revise a model makes them part of adaptation. Reserve other target examples for an independent assessment.
Changes that specialize the model to one narrow population can alter useful behavior elsewhere. Evaluate all conditions that remain relevant.
The requested gain is a difference between percentages on the same scale. It is not a relative increase divided by the old score.
## Active learning
For a binary probability, uncertainty is greatest when the two outcomes are hardest to distinguish, rather than near either extreme.
The active learner selects a query but still needs a reference label. Identify the role that supplies that missing information.
Uncertainty alone does not measure representativeness or usefulness. Unusual cases can remain difficult without informing common decisions.
Evaluate the inner signed expression, take its absolute value, and subtract from the outer constant in that order.
Several nearby queries may teach nearly the same thing. A labeling budget should account for overlap in their information.
Selected query labels influence training decisions. Final evaluation needs examples that have not participated in that process.
Ordinary prediction produces an output for a supplied input. Active learning makes a decision about which examples to obtain supervision for.
Divide the total labeling budget by the per-label cost. If the quotient is not whole, only complete affordable labels fit.
Model confidence can be wrong. A selection policy that only inspects uncertainty may neglect regions where the model is confidently mistaken.
Acquiring labels has a cost, and additional labels may have diminishing value. Compare the remaining resources with independent evidence of benefit.
## Artificial neuron
Compute each signed input-weight product, combine them, and then include the bias. The question stops before activation.
The bias contributes even when all inputs vanish. Contrast that with a weight, whose contribution depends on its input.
Match inputs with weights by position. Add the signed bias only after summing the products.
Follow the computation order: combine weighted inputs and the offset before applying the activation rule.
Zero weights remove the input-dependent terms. Check what remains before and after the activation is applied.
Composing only affine transformations yields another affine transformation. An additional kind of operation is needed for richer relationships.
Apply the activation after computing its input. For max(0, z), compare the signed pre-activation with the other argument.
Holding everything else fixed, the input's weight is the slope of the pre-activation with respect to that input.
Each input can contribute differently to the weighted sum. The model learns separate coefficients unless sharing is imposed.
The name is an analogy. This compact numerical rule omits much of the structure and behavior of a biological cell.
## Sigmoid
Substitute the input into 1/(1 + exp(−z)). Evaluate the exponential before adding in the denominator.
For a finite real input, the exponential is positive and finite mathematically. Examine the resulting fraction's strict bounds.
As the input grows, inspect what happens to exp(−z) in the denominator of the logistic formula.
A very negative input makes −z very positive. Track how that affects the denominator and hence the fraction.
Use σ′(z) = σ(z)(1 − σ(z)). Evaluate the sigmoid at the specified input before multiplying.
In saturated regions, output changes very little when input changes. The backward pass multiplies by that local rate.
An output constrained to a probability interval is not automatically calibrated. Compare forecasts with frequencies on appropriate held-out examples.
The sigmoid rises monotonically and is centered at input zero. Compare a candidate's position with that center.
Use the logistic symmetry relating σ(z) and σ(−z). They represent complementary positions around the function's center.
A bounded nonlinear curve does not behave like a linear map under arbitrary addition and scaling. Test one of those properties.
## ReLU
Apply the maximum operation separately to each input before adding. Negative inputs do not pass through unchanged.
Compare the positive input with zero. ReLU returns the larger of its two arguments.
Compare the negative input with zero. The activation does not take an absolute value.
On the positive side, the graph follows y = x. Determine the slope of that straight segment.
On the negative side, the graph is flat. A local change there does not change the output.
Compare the slope approaching zero from the left with the slope approaching it from the right.
Apply the rule to each coordinate independently. Keep the resulting coordinates in their original order.
For positive inputs, ReLU follows the input itself. Consider arbitrarily large positive values.
Backpropagation multiplies by the activation's local derivative. Check the derivative in the region occupied by every example.
ReLU is linear on each side separately, but its slope changes at the origin. Test addition across the two regions.
## Forward pass
Separate evaluating the current model from optimizing it. An ordinary forward calculation uses the parameter values already available.
Evaluate the specified prediction rule at the input. There is no parameter update requested in this calculation.
Computing an output and changing the rule that computes it are separate operations. A training update needs additional steps.
Intermediate results depend on earlier results. A graph records which values each operation must receive before it can run.
An operation cannot consume an intermediate value before it exists. Follow the parentheses' dependency order.
Inference applies the current model to an input. It needs the resulting output rather than a parameter-fitting step.
A prediction alone does not establish how far it is from the desired output. Supervised loss needs that reference.
Calculate the inner affine expression first, then apply ReLU to its signed result.
Derivatives of later operations can depend on values computed earlier. Retaining those values avoids recomputing them during differentiation.
Follow the direction of information: one pass evaluates intermediate quantities; the other traces how the loss changes through them.
## Backpropagation
A negative derivative means a small positive weight change locally lowers the loss. Apply the descent update with its subtraction sign carefully.
Backpropagation propagates sensitivity information through a computation graph. Distinguish that calculation from making predictions or choosing optimizer steps.
Differentiate the outer squared error, then include the prediction's derivative with respect to w. Both factors are required.
Compute the prediction and signed residual first. Multiply the squared-error derivative by the input factor from the inner model.
Derivative calculation supplies information about changes. A separate rule must use that information to choose and apply a parameter change.
A shared parameter affects the loss through each use. Total sensitivity includes every route rather than choosing just one.
Multiplying a long sequence of factors with magnitudes below one can shrink their combined contribution dramatically.
Automatic differentiation applies derivative rules to operations in the graph. Perturbing inputs numerically is a different differentiation method.
Varying an unused parameter leaves the computed loss unchanged. A derivative measures that dependence, not whether the parameter exists elsewhere.
The derivative can be accurate for a poorly chosen objective or unrepresentative dataset. Correct calculus does not validate the learning setup.
## Mini-batch gradient descent
Combine the two gradient contributions and normalize by the number being averaged. The update scale depends on using a mean or sum.
Add all per-example gradients and divide by the number of examples. Do not average only the extremes.
A training step need not inspect the entire dataset. Identify the group of examples used for that particular estimate.
A subset's gradient estimates the full objective's gradient imperfectly. Improving one subset need not improve the complete dataset at that step.
Batch size counts how many examples contribute to one gradient estimate. Apply that interpretation at its smallest positive size.
Contrast a subset-based estimate with a gradient computed using every training example before each update.
Fixed ordering can repeatedly group similar examples or patterns. Mixing examples changes those systematic batch compositions.
Scale the mean gradient by the learning rate, then subtract the scaled step from the current parameter.
Differentiating an average includes its normalization factor. Omitting it changes how gradient magnitude depends on batch size.
Runtime depends on hardware utilization, memory, update count, and convergence. Batch size alone does not determine the total.
## Epoch
First count batches in one complete dataset pass, then multiply by the number of passes requested.
The remaining examples still form a step when partial batches are kept. Round the batch count upward.
One term describes dataset coverage; the other describes an individual optimizer action. Several actions can occur during one pass.
Compute updates per complete pass and then repeat that count for the requested number of epochs.
Additional training can keep fitting sample-specific details after useful generalization stops improving. Check held-out behavior.
Larger batches cover more examples per step. With the same dataset, fewer steps are needed for a pass.
Dropping the remainder omits the final incomplete group. Compare rounding downward with rounding upward.
An epoch describes one traversal of the dataset under the training convention. Repeated epochs revisit those examples.
The relationship depends on batching and whether several batches contribute to one update. A single counter does not capture both quantities.
With exact divisibility, steps per pass equal dataset size divided by batch size. Only the numerator changes here.

Multiplying successive linear maps yields another linear map. Consider what extra expressive ability depth adds without another operation.
An affine composition remains affine. The intermediate activation must break that restriction to express a broader class of functions.
Extra layers change capacity and optimization difficulty. Improvement still depends on the data, fitting procedure, and task.

## Softmax
Equal logits have equal exponentials. Normalize those equal positive quantities by their combined total.
Symmetry assigns the same probability to each equal logit. Divide the total probability mass across all listed classes.
Every exponentiated score is divided by the same sum of scores. Sum the resulting fractions to see the normalization.
Exponentiation turns the added constant into a common factor. That factor appears in both numerator and denominator.
Exponentiation preserves the ordering of real logits, and the normalization denominator is shared by every class.

## Cross-entropy
For a one-hot target, loss is the negative logarithm of the assigned true-class probability. Consider how that function changes as probability increases.
