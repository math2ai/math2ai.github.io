How this is counted

  • A visit is one page load. A visitor is a browser seen for the first time, remembered by a yes-or-no flag in that browser. A second device, or cleared browser data, counts as a new visitor.
  • A lesson view is counted once per lesson per page load.
  • Every checked answer is counted, with the choice made and whether it was a first try. Nothing links answers to each other or to a person.
  • Online counts browsers with the site open and visible in the last few minutes, including this page. Each one sends a heartbeat about once a minute that says only which lesson is on screen, so the number can lag by a minute or two.
  • Browsers that send Do Not Track or Global Privacy Control are not counted. Offline copies of the course are not counted either.
  • The counters accept anonymous input, so treat the numbers as indicative.
